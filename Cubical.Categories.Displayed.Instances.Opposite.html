_^opᴰᴰ : ∀ {ℓ ℓ' ℓᴰ ℓᴰ' ℓᴰᴰ ℓᴰᴰ'} {C : Category ℓ ℓ'}{Cᴰ : Categoryᴰ C ℓᴰ ℓᴰ'}
  (Cᴰᴰ : Categoryᴰ (∫C Cᴰ) ℓᴰᴰ ℓᴰᴰ') → Categoryᴰ (∫C (Cᴰ ^opᴰ)) ℓᴰᴰ ℓᴰᴰ'
Cᴰᴰ ^opᴰᴰ =
  EqReindex.reindex (Cᴰᴰ ^opᴰ) ∫C-op-commute⁻ Eq.refl λ _ _ → Eq.refl
